# Notes — Index

Each note answers one question. Files are named after that question and grouped in a suggested learning order.

Use a note for revision, then explain the answer without reading it. Use [TEXTBOOK.md](../TEXTBOOK.md) when the short explanation is insufficient. Record unresolved technical details in [open-questions.md](../open-questions.md).

The notes distinguish normative HEVC behavior from encoder choices and teaching illustrations. For formal claims, follow the linked source ID into [SOURCES.md](../SOURCES.md).
