# Notes — Index

Each note answers **one question**. Files are named after the question they answer. Notes are grouped into **chapters** that follow a natural learning arc. Work top to bottom; the order is a suggested learning sequence.

**How to use a note:** open it, read it, then close it and try to re-explain the one-line answer and key points *without looking*. If you can't, you haven't learned it yet. Move anything you couldn't answer to [`../open-questions.md`](../open-questions.md).
